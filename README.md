# Genome Mapping

Маппинг ридов на референсный геном.
Риды выравниваются на референс, после чего считается, какая часть генома покрыта однозначно картированными ридами.

- референс: [GCF_000005845.2](https://ftp.ncbi.nlm.nih.gov/genomes/all/GCF/000/005/845/GCF_000005845.2_ASM584v2/GCF_000005845.2_ASM584v2_genomic.fna.gz);
- риды: [ERR022075](ftp://ftp.sra.ebi.ac.uk/vol1/fastq/ERR022/ERR022075/ERR022075_1.fastq.gz)

## Файл с ридами

`ERR022075_1.fastq`: 22 720 100 ридов по 100 букв.

Каждая запись состоит ровно из 4 строк:

```
@ERR022075.1000001 EAS600_70:5:6:3846:6108/1
AGCGATCGCATTTTTTTTGCAAG...
+
IIIIIIIIIGIIIIIIIIIIIHI...
```

| Строка | Содержимое |
|---|---|
| 1 | метаданные |
| 2 | рид |
| 3 | разделитель |
| 4 | качество: по символу на каждую букву последовательности |

### Качество

Шкала Phred+33: `Q = код символа − 33`, вероятность ошибки равна `10^(−Q/10)`. В файле встречаются символы от `!` до `I`, то есть Q от 0 до 40.

Если к концу рида качество падает ниже порога, весь хвост помечен символом `#`.

## Результаты

Референс: 4 641 652 п.н.

Проход по всем ридам как они есть: каждый рид ищется в референсе только целиком, точным совпадениеми только на одной цепи. Рид с ошибкой секвенирования, с `N` или с обратной цепи не находится. В покрытие идут риды, которые встретились в референсе ровно один раз.
