# Genome Mapping

Маппинг ридов на референсный геном.
Риды выравниваются на референс, после чего считается, какая часть генома покрыта однозначно картированными ридами.

- референс: [GCF_000005845.2](https://www.ncbi.nlm.nih.gov/datasets/genome/GCF_000005845.2/);
- риды: [ERR022075](https://www.ebi.ac.uk/ena/browser/view/ERR022075)
